# Стек

В проекте реализована структура данных стек.

## Как запустить

Run:
g++ main.c
ИЛИ
g++ main.c -D STACK_DEBUG
для режима дебага. Затем:
./a.exe

## Какие виды защиты реализованы

Проверка основных элементов структуры стек на корректность, канареечная защита, хешированная защита с алгоритмом djb2.

Ошибки разделены по группам info, warning, error и fatal.

Размер стека изменяется с гистерезисом.

Реализована функция Dump с цветным выводом, дополнительным выводом в режиме дебага (о том, на какой строчке, в какой функции и с каким именем был проинициализирован стек). 

Все сообщения из Dump также записываются в файл test.log, что позволяет просматривать их в неограниченном количестве.

Стек проверяется надёжной функцией верификации.

После выполнения нормальной работы нарочно ломается несколько стеков, выводятся сообщения об ошибке.
